Place these images here for the monster card template:

  heart.png  - Red heart with gold border (for Hit Points badge)
  shield.png - Dark shield with gold border (for Armor Class badge)

  paper_background.png - Light parchment/aged paper texture (Speed/CR/PB row, optional boxes, Creature Traits box)
  stone_background.png - Dark stone texture (Ability scores block)

  Creature type card backgrounds (top of card; creature image overlays if set):
  undead.png, fiend.png, aberration.png, dragon.png, celestial.png, construct.png, fey.png
  Any creature type without its own image uses aberration.png.

  assets/icons/ - SVG icons for card labels (CR, PB, Speed, Skills, etc.). See assets/icons/README.txt for the list of filenames. Each icon is displayed filled with the creature-type background.

The heart and shield are used as badge backgrounds with the numeric value centered on top. The paper and stone images tile as backgrounds for the listed sections.
