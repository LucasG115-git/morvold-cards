Ability Scores

Ability Scores (0–30)

Monsters use the same six ability scores as player characters, each ranging from 1 (minimum) to 30 (maximum). The modifier for each score is calculated the same way as for a player character.

If you're unsure what scores to assign, find a comparable creature in the Monster Manual and use its scores as a reference.

Saving Throws

Saving Throws

By default, a monster's saving throw bonus equals its relevant ability modifier. You can grant proficiency in a saving throw to make a creature more resistant to specific effects — the bonus then becomes the monster's proficiency bonus + the relevant ability modifier.

Saving throw proficiencies are most useful for offsetting a low ability score. For example, an undead creature with low Wisdom might still have a strong Wisdom save to reflect how difficult it is to charm, frighten, or turn.

Note: A monster with 3–4 saving throw proficiencies has its effective AC increased by 2 for CR purposes. A monster with 5 or more proficiencies increases effective AC by 4.

Skills

Skills

A monster proficient in a skill adds its proficiency bonus to the relevant ability check. You can grant expertise (double proficiency) to reflect exceptional mastery — for example, a doppelganger might have double proficiency in Deception. You might also grant Half Proficiency to several skills to represent a Jack-Of-All-Trades, as with a typical Bard.

Skill bonuses have no bearing on a monster's challenge rating. Assign them when they reinforce the creature's concept and role.

Languages

Languages

Languages have no bearing on CR. A monster can know as many languages as fits its concept, though most know one or two at most, and many beasts know none. A creature can understand a language without being able to speak it.

Creature Traits

Tip: Trait/action text supports notation like @damage[1d6|bonus=auto|type=slashing], @damage[1d10|bonus=str|type=bludgeoning/slashing], @save[dex|dc=auto], @save[dex/str|dc=auto], @failure[effect], and @success[effect]. Damage bonuses can be auto, str, dex, con, int, wis, cha, or none.

Actions

Tip: Inside an Attack's Hit text or an Action's Effect text, you can insert @damage[1d6|bonus=auto|type=slashing], @damage[1d10|bonus=str|type=bludgeoning/slashing], @save[con|dc=14], @save[dex/str|dc=auto], @failure[whatever happens on a failure], and @success[whatever happens on a success]. Optional |ability=cha lets you override which ability is used for an auto DC.

RPG card generator

  • To learn about what features are available to define a card, you can:
    • read the Basic documentation
    • read the Elements documentation
    • inspect the sample deck
  • If you find a bug or have a feature request, you can post them at the Github project site to maintain a record if you wish. However, it's not guarantee if and when they will be reviewed.
  • Some RPG systems are protected by copyright. Even if some spell/item data is freely available, it does not mean you may redistribute cards containing such data.
  • The user interface consists of three columns: The left column contains the menu and global settings. In the middle menu, you can select and edit individual cards. The right column contains a preview of the selected card.
  • To use the generator, either load the sample card deck ("Load sample"), load a card deck from a file ("Load from file"), or manually add some cards. When you're done, click on "Generate" to generate a document with all your cards, which can then be printed.

Printing notes

  • The generated cards open in a new tab or window. If you don't see any new tab or window, check your popup and script blockers. If that does not help, try disabling all addons.
  • Make sure you enable the printing of background images and colors in your browser.
  • Make sure your printer uses the correct paper size (same as in the editor).
  • You can use the double-sided (flip on long edge) print setting, but manually printing each side usually aligns the pages more accurately.
  • Do not scale the document to fit the page. Print at original size.
  • Some printers are not very precise (pages print slightly shifted or rotated) and the cards will not line up with the card backs. If this is the case, there's not much you can do. Try making the page background the same color as the cards or use the bleed option, so that you won't get any white edges on the card. If that does not help, try a different printer or print single-sided.
